# Quiz 1 · Le nouveau paradigme

À faire à la fin de l'étape 1, après la vidéo « Partie 1 », les diapositives 1 à 7 et les parties 1 à 3 du cours.

**Mode d'emploi :** pour chaque question, notez votre réponse (A, B ou C) **avant** d'ouvrir « Voir la réponse ». Comptez vos bonnes réponses à la fin. Vous pouvez refaire le quiz autant de fois que nécessaire.


## Question 1

Un agent IA, c'est :

- **A.** un modèle avec un rôle, des outils et des consignes
- **B.** un modèle seul
- **C.** un plugin de l'éditeur de code

<details><summary>Voir la réponse</summary>

**Réponse A.** Le modèle n'est que le moteur. Ce qui en fait un agent, c'est le rôle, les outils qu'il a le droit d'utiliser et les consignes qu'il suit.

</details>


## Question 2

Dans le nouveau cycle, qui code à l'étape « Implémenter » ?

- **A.** le développeur
- **B.** la CI (GitHub Actions)
- **C.** l'agent développeur

<details><summary>Voir la réponse</summary>

**Réponse C.** L'agent code seul sur une branche et ouvre une PR. Le développeur intervient avant (spécifier, déléguer) et après (revue, fusion).

</details>


## Question 3

À quelle étape du cycle aucun agent n'intervient-il ?

- **A.** Tester
- **B.** Déléguer
- **C.** Capitaliser

<details><summary>Voir la réponse</summary>

**Réponse B.** Choisir l'agent, le modèle et lancer la tâche reste une décision humaine.

</details>


## Question 4

Le « vibe coding », c'est :

- **A.** coder en écoutant de la musique
- **B.** programmer en binôme
- **C.** accepter du code généré sans le relire ni le tester

<details><summary>Voir la réponse</summary>

**Réponse C.** Demander vaguement et accepter sans lire donne un code qui marche en démo et casse en production. La méthode opposée : spécifier avant, contrôler après.

</details>


## Question 5

Qui décide de fusionner une pull request écrite par un agent ?

- **A.** un humain
- **B.** l'agent relecteur sécurité
- **C.** la CI, si les tests passent

<details><summary>Voir la réponse</summary>

**Réponse A.** C'est la règle d'or : une PR d'agent n'est fusionnée que si un humain l'a relue, peut l'expliquer et en assume la responsabilité.

</details>
